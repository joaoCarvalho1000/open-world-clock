Microsoft Store

  1. Open the listing. Go to the Open World Clock page on the Microsoft Store, or search the Microsoft Store app for “Open World Clock”.
  2. Select Get. It’s free. The Store downloads and installs it.
  3. Start it. Open Open World Clock from the Start menu and add your cities.

The Store keeps the app up to date. If the listing won’t open for you, the installer and the portable exe below are the same app.

winget

In Windows Terminal, PowerShell or Command Prompt, run:

winget install 9N88FR8M81BM -s msstore

This installs the Microsoft Store build, so it gets Store updates too. The first time you use the msstore source, winget may ask you to accept its terms.

Installer

  1. Download the installer. It’s Open-World-Clock-1.3.0-setup.exe, downloaded directly from openworldclock.com.
  2. Run it. It installs for your Windows user only, needs no admin rights, and adds Open World Clock to the Start menu and the desktop.

SHA-256 72eea47afd028fa8b04b1e3469e02fa93e7f46d6d47c2c20aa03008ae6314c9a

The installer is x64 only. On an ARM64 PC, get the Microsoft Store build, which runs natively. A native ARM64 build will come with the Microsoft Store version. If you had the app back when it was called World Clock, it upgrades that install in place and your cities carry over.

Portable exe

  1. Download it. Get Open-World-Clock-1.3.0-portable.exe, also straight from openworldclock.com.
  2. Run it from any folder. Nothing is installed.

“Windows protected your PC”

The installer and the portable exe aren’t code-signed yet. The first time you run one, Windows SmartScreen may stop it with a blue box that says “Windows protected your PC”. SmartScreen shows that for new programs without a signature or a download history; it isn’t a verdict on what the program does.

  1. Select More info. The publisher shows as unknown.
  2. Select Run anyway. The app starts.

Rather not click past a warning? The Microsoft Store build is signed by Microsoft and never shows it.The Microsoft Store version, coming soon, is signed by Microsoft and won’t show it. And the source code is on GitHub if you want to see what you’re running.

System requirements

  • Windows 10 or Windows 11. The Store build needs Windows 10 version 1809 or later.
  • An x64 or ARM64 processor. On ARM64, use the Microsoft Store build; the installer and the portable exe are x64 only.
  • An x64 processor. The installer and the portable exe are x64 only for now.
  • Nothing else. No runtime to install, no account, and no internet connection once it’s downloaded.

Updating

  • Microsoft Store: the Store updates it for you.
  • Installer: automatic updates stay off until the installer is code-signed. Download the new setup file and run it; it upgrades in place and keeps your cities.
  • Portable exe: it never updates itself. Download the new exe.

Release notes for every version are on GitHub Releases.

Uninstalling

  • Microsoft Store: right-click Open World Clock in the Start menu and choose Uninstall, or use Settings > Apps > Installed apps. Its settings go with it.
  • Installer: Settings > Apps > Installed apps > Open World Clock > Uninstall. Your settings stay in %APPDATA%\Open World Clock so a reinstall picks up where you left off; delete that folder to remove them.
  • Portable exe: delete the exe, and the %APPDATA%\Open World Clock folder if you want the settings gone too.

Used it when it was called World Clock? On first launch, Open World Clock copies your settings from the old World Clock folder. The old folder is left alone, and you can delete it.

What’s new in 1.3.0

  • New name, Open World Clock, and a new logo. Your settings carry over from World Clock.
  • A copy menu: Copy times, Copy for Discord (times that show in each reader’s own time zone), Copy in UTC and Save calendar invite.
  • Pick a meeting slot in the planner by clicking, dragging or Shift and the arrow keys, then copy it or save it as an invite.
  • The X button now hides the window to the tray, with a one-time notice. Quit is in the tray menu.
  • Zoom from 100% to 200% with Ctrl + + and Ctrl + -.
  • Better with the keyboard, screen readers and Windows contrast themes, after a WCAG 2.2 AA review.
  • Lighter: about 80 MB of memory in 3 processes, and about 0.2% of one CPU core while it sits in the tray.
  • Dates follow your Windows region format when it matches the app language. Help has two columns on wide windows and new tips.
  • Settings links to the website, to a bug report form that fills in your version, and to this page to check for updates.
  • Security hardening: Electron 44, the app loads only its own files, and links open only for a short list of sites.
  • The same app runs in your browser on the home page, with nothing to install.

Version 1.2.0 added real sunrise and sunset, the time scrubber, the meeting planner, the world map, clock-change notes and search by abbreviation or UTC offset.

The iPhone app is in the works too, with no date yet.
