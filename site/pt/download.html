Baixe o Open World Clock

É grátis para Windows 10 e 11, em x64 e ARM64. A Microsoft Store é o caminho mais fácil: um clique para instalar, e ele se atualiza sozinho. Se preferir não usar a Store, tem o winget, o instalador e o exe portátil.

É grátis para Windows 10 e 11. Baixe o instalador ou o exe portátil, os dois direto deste site. A versão da Microsoft Store chega em breve.

Baixar o exe portátil

Não pode instalar programas neste PC? Dá para testar direto na página inicial, no navegador.

Microsoft Store

  1. Abra a página do app. Acesse a página do Open World Clock na Microsoft Store ou procure “Open World Clock” no app Microsoft Store.
  2. Clique em Obter. É grátis. A Store baixa e instala o app.
  3. Abra o app. Abra o Open World Clock pelo menu Iniciar e adicione suas cidades.

A Store mantém o app atualizado. Se a página da Store não abrir para você, o instalador e o exe portátil aqui embaixo são o mesmo app.

winget

No Terminal do Windows, no PowerShell ou no Prompt de Comando, rode:

winget install 9N88FR8M81BM -s msstore

Isso instala a versão da Microsoft Store, que também recebe as atualizações da Store. Na primeira vez que você usar a fonte msstore, o winget pode pedir que você aceite os termos dela.

Instalador

  1. Baixe o instalador. É o Open-World-Clock-1.3.2-setup.exe, baixado direto do openworldclock.com.
  2. Execute o instalador. Ele instala só para o seu usuário do Windows, não pede permissão de administrador e coloca o Open World Clock no menu Iniciar e na área de trabalho.

SHA-256 99343c3ff7a404b97457bf499e134b45e38caff36e7d20725c833f5c839cd7c5

O instalador é só x64. Num PC ARM64, use a versão da Microsoft Store, que roda nativamente. A versão nativa para ARM64 vem junto com a da Microsoft Store. Se você tinha o app quando ele ainda se chamava World Clock, a instalação antiga é atualizada e suas cidades continuam lá.

Exe portátil

  1. Baixe. Pegue o Open-World-Clock-1.3.2-portable.exe, também direto do openworldclock.com.
  2. Rode de qualquer pasta. Nada é instalado.

SHA-256 130dfce81234a85ecdfcd5ed43a72af483a405aa48a1e0d8c8f2914515c3645f

Ele nunca se atualiza sozinho; para atualizar, baixe o exe novo. É só x64, então num PC ARM64 use a versão da Microsoft Store, que roda nativamente. É só x64; a versão nativa para ARM64 vem junto com a da Microsoft Store. As configurações continuam indo para %APPDATA%\Open World Clock. Se você ativar a opção de iniciar com o Windows e depois mudar o exe de lugar, ative de novo para o Windows encontrar o arquivo no lugar novo.

Qual eu escolho?

Resumindo: a Store, a não ser que você tenha um motivo para não usar.

“O Windows protegeu o computador”

O instalador e o exe portátil ainda não têm assinatura de código. Na primeira vez que você abrir um deles, o SmartScreen do Windows pode barrar com uma caixa azul que diz “O Windows protegeu o computador”. O SmartScreen mostra isso para programas novos, sem assinatura ou sem histórico de downloads; não é um veredito sobre o que o programa faz.

  1. Clique em Mais informações. O editor aparece como desconhecido.
  2. Clique em Executar assim mesmo. O app abre.

Requisitos do sistema

  • Windows 10 ou Windows 11. A versão da Store precisa do Windows 10 versão 1809 ou mais recente.
  • Um processador x64 ou ARM64. No ARM64, use a versão da Microsoft Store; o instalador e o exe portátil são só x64.
  • Um processador x64. Por enquanto, o instalador e o exe portátil são só x64.
  • Mais nada. Nenhum runtime para instalar, nenhum cadastro e nenhuma conexão com a internet depois de baixado.

Como atualizar

  • Microsoft Store: a Store atualiza para você.
  • Instalador: as atualizações automáticas ficam desligadas até o instalador ter assinatura de código. Baixe o instalador novo e execute; ele atualiza a instalação e mantém suas cidades.
  • Exe portátil: ele nunca se atualiza sozinho. Baixe o exe novo.

As notas de cada versão estão no GitHub Releases.

Como desinstalar

  • Microsoft Store: clique com o botão direito no Open World Clock no menu Iniciar e escolha Desinstalar, ou use Configurações > Aplicativos > Aplicativos instalados. As configurações vão junto.
  • Instalador: Configurações > Aplicativos > Aplicativos instalados > Open World Clock > Desinstalar. Suas configurações continuam em %APPDATA%\Open World Clock, para uma reinstalação continuar de onde parou; apague essa pasta para removê-las.
  • Exe portátil: apague o exe e, se quiser se livrar das configurações também, a pasta %APPDATA%\Open World Clock.

Usava o app quando ele se chamava World Clock? Na primeira vez que abre, o Open World Clock copia suas configurações da pasta antiga do World Clock. A pasta antiga fica intacta, e você pode apagá-la.

Novidades da versão 1.3.2

  • O planejador de reuniões abre do tamanho que precisa, sem espaço vazio, e mostra a hora em cada célula em qualquer layout.
  • Nome novo, Open World Clock, e logotipo novo. Suas configurações do World Clock vêm junto.
  • Um menu de cópia: Copiar horários, Copiar para o Discord (horários que aparecem no fuso de quem lê), Copiar em UTC e Salvar convite de calendário.
  • Escolha um horário de reunião no planejador clicando, arrastando ou com Shift e as setas, e depois copie ou salve como convite.
  • O botão X agora esconde a janela na bandeja, com um aviso só na primeira vez. A opção Sair fica no menu da bandeja.
  • Zoom de 100% a 200% com Ctrl + + e Ctrl + -.
  • Funciona melhor com teclado, leitores de tela e temas de contraste do Windows, depois de uma revisão WCAG 2.2 AA.
  • Mais leve: cerca de 80 MB de memória em 3 processos, e cerca de 0,2% de um núcleo da CPU enquanto fica na bandeja.
  • As datas seguem o formato regional do Windows quando ele combina com o idioma do app. A Ajuda ganhou duas colunas em janelas largas e dicas novas.
  • As Configurações ganharam links para o site, para relatar um problema (o formulário já vem com a sua versão preenchida) e para verificar atualizações nesta página.
  • Segurança reforçada: Electron 44, o app carrega só os próprios arquivos, e ele só abre links de uma lista curta de sites.
  • O mesmo app roda no seu navegador, na página inicial, sem instalar nada.

A versão 1.2.0 trouxe o nascer e o pôr do sol reais, o ajuste do horário com a roda do mouse, o planejador de reuniões, o mapa-múndi, os avisos de mudança de relógio e a busca por sigla ou fuso UTC.

O app para iPhone também está a caminho, ainda sem data.
