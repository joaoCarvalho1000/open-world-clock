v1.0.0 (2026-09-22): initial release. Card strip layout, live clocks, time converter, zone search, tray, always on top, themes.

v1.0.0 cleanup: validated settings IPC, batched saves, OS-shutdown-safe quit, portable-aware launch at login, canonical zone ids, fixed search dropdown clipping, tighter CSP.

Deep review: fixed DST-gap conversion (spring-forward times now shift forward like the OS), stale converter source after removing its city, legacy local zone ids, unknown zones in settings no longer break rendering, and a save-reply race that could revert rapid edits. Added an in-app test suite (npm test, 48 checks).

v1.1.0: light redesign (frosted glass, hairlines, one accent), custom city labels, strip / compact / vertical layouts, Portuguese and Spanish, one-time tips (now behind the ? button), copy converted times, screen reader announcements, localized tray, arm64 builds, single owner for window geometry (settings panel, snapping, multi-monitor).

v1.2.0: motion system (cards, time, top bar, popovers, settings, ambient) that respects reduced motion; real sunrise and sunset per city with sky colors, "likely asleep" cue, time scrubber (wheel, day-line drag, keys), abbreviation and UTC offset search; meeting planner with per-city working hours, overlap band and date shortcuts; clock-change notes; world map view with live day and night; top-bar layout switch; per-view window sizes; Windows 11 Snap with native acrylic backdrop; new day/night dial icon.

v1.2.0 go-live fixes:
- Window sizes are exact at fractional display scaling (115%, 125%): restored sizes no longer come back 4px bigger and the first launch opens at exactly 1160x250.
- Picking a layout while the planner or map is open closes it and uses that layout's size; the vertical layout keeps its own planner and map sizes.
- Card menu and help fit short windows (two columns, placed beside their button when needed, never over it, scroll as a last resort).
- Narrow strip windows use the stacked top bar; tall strip windows wrap cards into rows instead of leaving empty bands.
- Status toast for invalid times and "Copied" when the hint line is hidden; planner rows fade at the edge when they scroll; keyboard focus kept after moving a card from its menu; options button in the vertical layout.
- Clock-change note moved under the phase with short text ("Clocks −1h tomorrow"); a picked date shows on every card; converted cards use a ring on the day-line dot instead of an underline; dashed keyboard focus ring.
- Search ignores accents, says when nothing matches or the city is already added, and shows countries (localized) instead of continents; city names translated in Portuguese and Spanish.
- Day-line drag converts from that card's city; one wheel notch is one 15-minute step at any scaling; copy does nothing without cities.
- Settings is a modal (everything behind it inert); opacity slider shows its fill; only selectable rows highlight.
- Robustness: atomic settings saves with a backup, crashed or hung page reloads, OS shutdown saves, OS time zone changes are picked up, conversions keep their date across midnight, date chips count from the source city, lighter per-second updates, Windows display language detection (pt-PT, es-419), app user model id, stricter IPC sender check.
- Auto-update is off unless a signed build opts in (build.extraMetadata.wcUpdates). The Store startup task is declared disabled by default (Windows Settings > Apps > Startup).
- No en or em dashes in any UI string; unused strings removed.

v1.3.0 details: security audit fixes.
- Electron 33.4.11 (out of support) to Electron 44.4.5, the newest stable major; electron-builder 25 to 26.16.1. Clipboard calls are awaited (Promise-based in Electron 44) and the test suite reads the new `console-message` event object.
- Electron fuses set at package time (scripts/after-pack.js with @electron/fuses): no ELECTRON_RUN_AS_NODE, NODE_OPTIONS or --inspect, asar integrity checked, app loaded only from app.asar, cookie encryption on. The file:// privileges fuse stays at its default, because the window loads index.html from file:// inside app.asar.
- No application menu (copy and paste in text fields still work), every web permission request and check denied, no DevTools in installed builds, no webviews or new windows, and links open in the browser only for https on openworldclock.com, github.com and apps.microsoft.com.
- Website analytics proxy is a strict allowlist: only the PostHog SDK loader, this project's remote config and the event endpoints; everything else 404; GET, POST and OPTIONS only; bodies over 64 KB refused; only a few request headers forwarded (never cookies, Authorization or Referer); Set-Cookie removed. Unit tests in test/unit/proxy.test.js.
- Wrangler pinned to 4.137.0 with a lockfile in cloudflare/. iOS CI (apple/ci/ios.yml): macos-26 runner with Xcode 26 required, actions/checkout pinned to the v7.0.1 commit, XcodeGen 2.46.0 downloaded with a SHA-256 check instead of brew. Default branch renamed to main.
- Privacy policy and page: the installer build makes no network requests today (update checks stay off until it is signed); the "IP discarded" statement names the PostHog project setting it relies on; uninstall wording now matches what the Store and installer builds actually do.
- .gitignore covers signing material, env files, Wrangler and Xcode local state; a stray npm cache under build/ is no longer tracked.
