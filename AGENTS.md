# Contributor checks

- Follow the maintainer checks in `CONTRIBUTING.md`, including website tests for SEO changes.
- Do not use em or en dashes in website copy or metadata. Use periods, commas, colons, or parentheses.
- City-pair pages are generated by `scripts/build-seo-pages.mjs` from `cloudflare/seo-content.mjs`. Update the source when changing generated content so a rebuild preserves the change.
- Keep metadata, structured data, language links, sitemap dates, asset versions and CSP hashes consistent. Run checks without rewriting files to conceal a failure.
- Review the latest PR commit. Existing failures on `main` must be resolved before unattended merges; never disable tests or audits to make a bot PR green.
- Website checks do not authorize deployment, desktop releases, or iOS publication. Never deploy an uncommitted working tree.
